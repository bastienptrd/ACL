Compte rendu rétrospective
SPRINT V2 (19/10/2026 - 05/11/2026)
Groupe DARREN

# I. Informations générales

Le projet consiste en la réalisation d'un jeu de style labyrinthe, dans un thème de jeu d'horreur.
Notre groupe est composé des membres suivants : Bastien Petrod, Alexis Cicurel, Deya Ben-Dali, Ethan Julien, Léo Simonet

# II. Résumé du sprint

Pour ce second sprint, l'objectif était avant tout d'avoir une version fonctionnelle avec la première boucle du jeu

Nos objectifs pour ce second sprint étaient les suivants :

- Avoir un menus principale
- Avoir une génération du labyrinthe
- Pouvoir se déplacer dans 8 directions
- Avoir l'apparition enemis
- Des déplacements des enemis
- Des dégats au contacte des enemis
- Un menu de fin

# III. Bilan

Les objectifs sont partiellement atteints. Toutes les tâches n'ont pas été effectuées dans leurs totalité.

La classe Enemi n'étant pas été codé par Ethan, l'ensemble des features autour des enemis n'ont pas pu être coder.

Néanmoins l'ensemble de la boucle de jeu et des menus ont été mis en place.

# IV. Retour du professeur et consignes

# V. Ce qui a posé problème

Beaucoup de code devait s'appuyer les uns sur les autres. Cela a fini par amener des problèmes dans le developpement des features car avec certaine partie du code manquante d'autre feature ne pouvait pas être implémenté.

# VI. Ce qu'on en tire comme conclusion

Nous devons plus communiqué entre nous sur l'avancement du projet afin de ne pas arriver dans une situation de bloquage.
Nous devons trouver des tâches moins dépendante les unes des autres pour éviter qu'une personne crée du retard sur le travail des autres personnes du groupe.
