Jeu : 

	labyrinthe


Fonctionnalité : 

	Héros :
		- Déplacement Haut Bas Gauche Droite
		- Collision avec l'environnement
		- Peut prendre des dégâts
		- Lampe et cercle de lumière autour du joueur

	Labyrinthe : 
		- Générer aléatoirement à partir d'une seed et d'une taille
		- Le Labyrinthe possède un départ et une arrivée

	Ennemis : 
		- Les ennemis se déplacent vers le joueur 


	Génération du labyrinthe : créer un labyrinthe à partir de deux paramètres longueur et hauteur
	Déplacement personnage : Haut Bas Gauche Droite
	Collision avec les murs : Le joueur ne peut passer à travers les murs
	Personnage 2D avec animation : le joueur doit donner l'impression de marcher ne non de voler
	Système de départ arrivé : le joueur part d'un point de départ et atteindre un objectif dans le labyrinthe
	Menus : possibilité de lancer une partie (création de labyrinthe puis début au départ) de mettre en pause

Backlog : 

	Package pour faire le labyrinthe
	Objet personnage (sprite, déplacement + collision, éventuellement animation)
	Images
	Système d'affichage
